# FiveM Radio System

A comprehensive radio system for FiveM servers with multiple channels and player-specific settings.

## Features

- Multiple radio channels
- Player-specific channel settings
- Message broadcasting over radio channels

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files.
2. Place them in your FiveM server's resources folder.
3. Import the database.sql file into your MySQL database.
4. Add `start radio-system` to your server.cfg file.

## Usage

- Players can press the N key to send a radio message.
- The radio system will broadcast the message to all players on the same channel.

## Configuration

The script can be configured in the config.lua file. You can set the radio channels, default channel, and radio volume.
